# Teaneck Square waitlist preview

A responsive, buildless client mockup based on the requested five fields: full name, email, phone, projected move-in date, and bedroom count. Homepage buttons lead to an inline waitlist form; valid input demonstrates a confirmation screen.

Open `index.html` directly, or serve this directory with a static HTTP server. No dependencies or build step are needed.

## GitHub Pages

Upload this directory's contents to a new repository. In repository Settings → Pages, select **Deploy from a branch**, choose the main branch and `/ (root)`, then save. Use the URL GitHub provides to share the preview. No secrets or account details belong in this repository.

## Preview boundaries

This is a design concept, not the live property website. The form does not submit, transmit, or persist any entered information. Images load from Teaneck Square's existing public website; those images remain subject to the owner's rights and their source availability. Links to apartments, amenities, and gallery open the existing property website.

The copy and one/two/three-bedroom choices are proposed presentation details. Before production, confirm required fields, availability notification wording, privacy requirements, and the destination for submissions. GitHub Pages serves static pages; collecting submissions or connecting Google Sheets requires a separately configured form service or backend. Never place private Google credentials in client code.
